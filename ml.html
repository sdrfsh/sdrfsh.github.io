2026

In 2026 I put the two together

  1. rebuilt 2026

    Real-Time Activity & Intention Recognition: MSc thesis to open-source system

    Rebuilt the system in 2026 as a tested Python codebase with a CLI for data prep, training, batch prediction and live webcam prediction that runs locally, without the cloud.

    The released model on Hugging Face reaches 98.84% accuracy and F1 0.99 on the held-out test set.

    • Model on Hugging Face
    • Source on GitHub

  2. Sep 2026

    adaptive-motion-preprocessing: open-source Python package

    Python package that turns video frames into same-size motion images for neural networks (older frames dim, newer ones bright), with motion triggering, noise reduction and background subtraction as pluggable stages.

    Released on PyPI. CI runs the tests on Linux, Windows and macOS, and every release has to pass it first.

    • On PyPI
    • Source on GitHub
    • CI workflow
    • Medium write-up

  3. Oct 2026

    Daily Journal Sentiment Analysis (private GitLab repos)

    Reads journal entries in English or Persian and decides if the day was good, neutral or bad, and why.

    Compared a zero-shot model, a sentiment model and a local LLM on my own labels (accuracy, speed, GPU use).

    Runs as an API service that other apps call. Every new version is built and published automatically through GitLab CI/CD.
